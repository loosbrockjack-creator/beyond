# Learning-Driven Implementations

This folder stores implementation briefs and completion notes created from the learning process.

## Pending briefs

Store explicit implementation briefs directly in this folder using a descriptive filename.

Example:

`context-engineering-audit.md`

## Completed work

Store Claude's learning-oriented completion notes in:

`ai-learning/implementation/completed/`

An implementation should not begin merely because a concept appears in the curriculum or tutor state. It must be explicitly requested through a brief or GitHub issue.
