# 16-Week AI Learning Roadmap

This mirrors the current course order used by Beyond.

The weekly research process must revalidate each topic before building that week's curriculum. If a future topic becomes materially lower-value because AI has changed, the curator should recommend a reframe or replacement. Do not change the app's course order without explicit approval.

## Module 1: Agent Core

1. AI agents and agentic systems
2. Working effectively with AI coding agents
3. Tool use and function calling
4. Context engineering

## Module 2: Reach and Reliability

5. APIs, integrations, and webhooks
6. MCP, connectors, and interoperability
7. AI evals, verification, and reliability
8. Computer-use and browser agents

## Module 3: Knowledge and Boundaries

9. Retrieval, RAG, and search
10. Multimodal AI and voice
11. Agent memory, state, and persistent work
12. AI security, permissions, and guardrails

## Module 4: Structure and Economics

13. Structured outputs and deterministic boundaries
14. Workflow decomposition and business-process redesign
15. Model selection, routing, economics, and operations
16. Fine-tuning, distillation, synthetic data, and model customization

## Curriculum selection principles

Every week should optimize for durable leverage, not temporary product trivia.

Prioritize:
- current material,
- durable mental models,
- clear explanatory content,
- practical business relevance,
- system design and judgment,
- verification and reliability,
- skills that become more valuable as models improve.

Deprioritize:
- syntax memorization,
- framework-specific implementation detail,
- raw SDK documentation,
- generic AI news,
- clickbait,
- content that is mainly relevant to professional ML engineers.

Older resources may be included only when the concept is durable and the resource remains unusually clear after current verification.
