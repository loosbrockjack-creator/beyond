# Weekly Curricula

Store one final curriculum file per week in this folder.

Naming convention:

`week-XX-topic-slug.md`

Examples:
- `week-01-ai-agents-and-agentic-systems.md`
- `week-02-working-effectively-with-ai-coding-agents.md`

Each curriculum should contain only the final selected learning material.

Do not store rejected links, raw research notes, or copied chat transcripts here.
